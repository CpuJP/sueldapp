# Reglas de git

- Nunca añadir `.ods`, `.sqlite3`, `logs/`, `exports/` ni `.csv` (están en `.gitignore`; no usar `git add -f`).
- Commits pequeños con Conventional Commits en español: `feat:`, `fix:`, `docs:`, `test:`, `refactor:`.
- `git push` solo con confirmación del usuario.
- Revisar `git status` antes de cada commit para asegurar que no entra ningún dato.
